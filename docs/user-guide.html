1. Gioi thieu

Odoo Installer la ung dung desktop (Windows) giup cai dat moi truong phat trien Odoo mot cham, ho tro 3 phien ban:

VersionPythonPostgreSQLMau
Odoo 15Python 3.10PostgreSQL 14Xanh duong
Odoo 17Python 3.11PostgreSQL 16Cam
Odoo 19Python 3.12PostgreSQL 16 + pgvectorXanh la

Ung dung tu dong cai dat: Git, VS Code, Python, PostgreSQL, clone Odoo source, tao virtual environment, cai dependencies, tao project.

2. Cai dat ung dung

1 Tai file Odoo Installer Setup 1.0.27.exe

Chi can 1 file .exe duy nhat. Khong can cai them bat ky thu gi.

2 Chay file cai dat

Double-click file .exe → Chon thu muc cai dat → Nhan Install.

[Screenshot: Giao dien cai dat Windows]
3 Khoi dong ung dung

Sau khi cai xong, ung dung tu dong mo. Hoac tim trong Start Menu: Odoo Installer.

Ung dung can quyen Administrator de cai dat PostgreSQL va tao symlink.

5. Full Install - Cai dat toan bo

Nhan tab Full Install tren thanh navigation.

[Screenshot: Man hinh Full Install voi 8 step cards]

8 Buoc cai dat:

STTBuocMo ta
1NginxCai HTTPS reverse proxy
2GitCai Git for Windows (version control)
3VS CodeCai Visual Studio Code (code editor)
4PythonCai Python (3.10/3.11/3.12 tuy version)
5PostgreSQLCai database server
6Clone OdooTai source code Odoo tu GitHub
7Virtual EnvTao moi truong ao Python
8Pip RequirementsCai cac thu vien Python can thiet
A Cach 1: Cai dat toan bo (Khuyen nghi)
  1. Chon phien ban Odoo (15/17/19) o dropdown tren cung.
  2. Nhan nut "Install Everything".
  3. Cho doi - cac buoc chay tu dong, hien thi tien trinh.
  4. Khi xong, moi buoc hien dau tick xanh hoac X do.
B Cach 2: Cai tung buoc
  1. Click vao tung Step Card de chay rieng tung buoc.
  2. Vi du: Chi can cai Python thi click vao card "Python".
  3. Cac buoc da hoan thanh se hien dau tick xanh.
Luu y: Buoc 6 (Clone Odoo) can co Git da cai. Buoc 7-8 can co Python da cai va Odoo da clone. Nen chay "Install Everything" de dam bao thu tu dung.

2 Advanced Config (tuy chon)

Click vao "Advanced Config" de mo cac tuy chon nang cao:

  • Log Level: error (mac dinh), warn, info, debug
  • Workers: 0 (mac dinh, development mode)
  • DB Filter: Loc database theo pattern
  • Proxy Mode: True/False
3 Nhan "Create Project"

He thong se tao:

  • Thu muc project voi addons/, .vscode/, data/
  • Junction link toi Odoo source dung chung
  • File odoo.conf voi cau hinh da nhap
  • File .vscode/launch.json de debug bang VS Code
  • Domain trong file hosts
HTTP Port tu dong tang: He thong scan tat ca port cua cac project hien tai (ca http_port va longpolling_port) roi tim port tiep theo khong bi trung. Longpolling port = http_port + 3.

8. Start / Stop Odoo

▶ Start Odoo
  1. Nhan nut Start (mau xanh) tren card hoac trong popup Detail.
  2. He thong tu dong:
    • Kiem tra PostgreSQL - neu dung thi tu dong khoi dong
    • Tao DB user neu chua co
    • Chay python odoo-bin -c odoo.conf
  3. Cho khoang 5-15 giay, Odoo khoi dong.
  4. Trinh duyet tu dong mo tai dia chi project.
  5. Card doi trang thai thanh running, nut doi thanh Stop.
[Screenshot: Project dang running]
■ Stop Odoo
  1. Nhan nut Stop (mau do) tren card hoac trong popup Detail.
  2. He thong tim process dang listen tren port va kill.
  3. Card doi trang thai thanh stopped, nut doi thanh Start.
Tu dong dong bo: Trang thai running/stopped duoc kiem tra moi 10 giay. Neu ban dung Odoo tu terminal, UI se tu dong cap nhat.

12. Cac loi thuong gap

LoiNguyen nhanCach xu ly
Failed to create symlink Khong co quyen Admin Chay ung dung voi quyen Administrator
PostgreSQL is not running PostgreSQL chua khoi dong He thong tu dong khoi dong khi Start Odoo. Neu van loi, mo Services.msc va start PostgreSQL
Port da duoc su dung Trung port voi ung dung khac Doi HTTP Port trong Edit Config hoac khi tao project
X509_V_FLAG_NOTIFY_POLICY pyOpenSSL/cryptography xung dot version Chay: pip install --upgrade cryptography pyOpenSSL trong venv
requirements.txt not found Chua clone Odoo source Chay buoc "Clone Odoo" truoc
Venv not found Chua tao virtual environment Chay buoc "Virtual Env" truoc
Odoo started but not responding Odoo dang khoi dong cham hoac bi loi Kiem tra Installation Log de xem chi tiet loi
